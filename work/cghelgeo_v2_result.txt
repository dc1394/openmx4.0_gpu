Findings
--------
1. Numerics are exactly preserved: the new binary reproduces the old
   binary's Utot bit-for-bit on both paths (GPU -4154.835898598240,
   CPU -4154.835898595155), all 70/70 SCF, no watchdog kills.
2. Host memory is the real change: GPU peak 104-105 -> 97-99 GiB and CPU
   peak 99 -> 90-91 GiB per node.  The CPU-side ~8.5 GiB saving is the
   dense construct table (164 MB x 48 ranks) that ELPA ranks used to build
   and never read.
3. Timings moved by ~1.5% (GPU) and ~0.1% (CPU) -- at or below the
   node-to-node spread.  The 4-6% GPU gains suggested by the two earlier
   single-sample runs (memfix2/memfix3) were node-pair luck, not a
   systematic effect; the three-run mean settles it.
